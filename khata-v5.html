⚡ 5-minute setup guide

  1. Go to console.cloud.google.com
  2. Create a new project (name it anything)
  3. Go to APIs & Services → OAuth consent screen
    Set type to External, fill app name
  4. Go to APIs & Services → Credentials
    Click Create Credentials → OAuth 2.0 Client ID
  5. Choose Web application, add your page URL to Authorized origins
  6. Copy the Client ID and paste it above
  7. Enable Google Drive API in APIs & Services → Library
